# Bake & Bliss

Website for the Bake & Bliss cake business — online cake orders and paid video baking classes.

## Features

- **Home** — brand hero, class highlights, order CTA
- **Classes** — video sessions at **LKR 2,000/=** each
- **Class access** — pay, then WhatsApp **+970 345 6448** for the video link
- **Order cakes** — online order form sent via WhatsApp

### Class sessions

Cake tool introduction, butter cake, chocolate cake, marble cake, ribbon cake, gateau cake, jar cakes, cupcakes, cake structures, wedding cake, and other specials.

## Develop

```bash
npm install
npm run dev
```

## Build
